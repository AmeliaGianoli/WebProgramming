Image Gallery Component

Examine the code for the createGallery component function. Notice the following:

  • The el parameter allows you to display the gallery inside of any element
  • The images parameter allows you to display any images
  • The function creates all the HTML elements needed to display a gallery and appends it to the el parameter
  • The function includes all code/logic to make an image gallery work

All of these features make it a reusable component that can appended to any element and display any images.
